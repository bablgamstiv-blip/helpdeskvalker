# HelpDeskEddy

HelpDeskEddy — демонстрационная русскоязычная система поддержки клиентов на Java 21 и Spring Boot 3. Веб-интерфейс серверный: Spring MVC, Thymeleaf и Bootstrap 5. Обращения, клиенты, агенты, сообщения и статьи хранятся в H2 в памяти. Данные автоматически загружаются при первом запуске приложения.

Проект предназначен для демонстрации пользовательского интерфейса и сценариев help desk. Реальной доставки сообщений, телефонии, подключения мессенджеров, регистрации, управления пользователями или постоянного хранения данных в нём нет.

## Быстрый запуск

Убедитесь, что в системе доступны **JDK 21** и **Apache Maven 3.9+**. Откройте **новое окно CMD** и выполните:

```cmd
cd /d "C:\Users\student164\Desktop\kotlin\Новая папка"
mvn spring-boot:run
```

Когда в журнале появится `Started HelpDeskEddyApplication`, откройте <http://localhost:8080>.

**Демо-вход:** `admin` / `admin`.

Чтобы завершить сервер, вернитесь в окно CMD и нажмите `Ctrl+C`.

### Установка инструментов в Windows

JDK можно установить через `winget` из CMD:

```cmd
winget install --id EclipseAdoptium.Temurin.21.JDK --exact --accept-source-agreements --accept-package-agreements
```

Затем откройте новое окно CMD и проверьте:

```cmd
java --version
mvn --version
```

Для установки Apache Maven, если его нет в `winget`, скачайте официальный архив Maven и распакуйте его, например, в `%USERPROFILE%\.m2\tools`:

```powershell
$version = "3.9.11"
$tools = Join-Path $env:USERPROFILE ".m2\tools"
$archive = Join-Path $env:TEMP "apache-maven-$version-bin.zip"
New-Item -ItemType Directory -Force -Path $tools | Out-Null
curl.exe -fL "https://archive.apache.org/dist/maven/maven-3/$version/binaries/apache-maven-$version-bin.zip" -o $archive
tar.exe -xf $archive -C $tools
```

Добавьте каталог `%USERPROFILE%\.m2\tools\apache-maven-3.9.11\bin` в пользовательский `Path`, задайте `JAVA_HOME` для JDK 21 и откройте новое окно CMD. Загрузка зависимостей Maven при первой сборке требует доступа к Maven Central.

### Проверки разработки

В CMD из папки проекта:

```cmd
mvn test
mvn spring-boot:run
```

`mvn test` выполняет модульные тесты SLA и интеграционные проверки страниц, поиска, фильтров и действий с обращениями. Во втором окне CMD можно проверить страницу входа командой:

```cmd
curl.exe -I http://localhost:8080/login
```

Подробная история проекта, его файлов и проверок находится в [`docs/DEVELOPMENT_LOG.md`](docs/DEVELOPMENT_LOG.md).

## Разделы сайта

| Страница | Возможности |
|---|---|
| `/login` | Демо-вход, сообщение об ошибочных учётных данных. |
| `/dashboard` | Количество новых, находящихся в работе, просроченных и решённых обращений; график по дням, круговая диаграмма каналов, список последних обращений. |
| `/tickets` | Очередь из 25 демонстрационных обращений; фильтры по статусу, каналу и приоритету; поиск по теме, имени клиента и номеру. |
| `/tickets/{id}` | Карточка обращения, клиентская переписка, сохранение ответа и внутренней заметки, изменение статуса, приоритета и исполнителя, сведения об SLA. |
| `/knowledge` | Категории и поиск демонстрационных статей по заголовку, описанию, категории и содержимому. |
| `/knowledge/{id}` | Статья базы знаний с полным текстом и ссылкой на очередь обращений. |
| `/sla` | Распределение обращений по времени SLA и полный список сроков. |
| `/automation` | Примеры правил обработки и шаблонов сообщений; только просмотр. |
| `/settings` | Демонстрационные сведения об организации, команде, каналах и хранении данных; только просмотр. |

Все рабочие страницы доступны после входа. Независимо от раздела можно выполнить поиск по обращениям из поля поиска в шапке и открыть список новых обращений кнопкой уведомлений. На узком экране навигация открывается кнопкой меню и закрывается кнопкой внутри меню, повторным нажатием или клавишей `Esc`.

### SLA-индикаторы

Время ответа берётся из демонстрационных данных обращения: отрицательное значение — срок нарушен (**красный**); от 0 до 30 минут включительно — срок скоро истекает (**жёлтый**); более 30 минут — обращение в сроке (**зелёный**). Значения отображаются в списке, на карточке обращения и на странице `/sla`. Счётчик «Просрочено» отражает значение SLA в демо-записи и не является вычислением реального времени.

## Демо-данные и хранение

При первом запуске создаются:

- 25 обращений из Email, Telegram, WhatsApp, чата, телефона и VK;
- 5 агентов и 10 клиентов;
- переписка и образцы внутренних заметок к обращениям;
- 8 статей базы знаний по аккаунту, оплате, настройкам, безопасности, заказам и работе с сервисом;
- демонстрационные значения SLA, приоритетов и статусов.

H2 работает в режиме **in-memory**. При завершении или перезапуске приложения база создаётся заново, а изменения ответов и обращений сбрасываются.

## Внешний вид

Скриншоты в этой поставке не приложены. Ниже приведено описание экранов для предварительной оценки дизайна:

1. **Вход** — отдельная светлая карточка, логотип HelpDeskEddy, поля логина и пароля, подсказка с демо-доступом.
2. **Дашборд** — боковая панель, карточки показателей, фиолетовый график обращений, круговая диаграмма каналов и таблица недавних обращений.
3. **Список обращений** — панель поиска и фильтров, таблица с цветными каналами, статусами, приоритетами и индикаторами SLA.
4. **Карточка обращения** — сообщения клиента и агента, выделенные внутренние заметки, форма ответа и боковая панель редактирования.
5. **База знаний** — поиск, категории, карточки статей и отдельный экран чтения полной инструкции.
6. **SLA** — сводные цветные индикаторы и таблица сроков по обращениям.
7. **Автоматизация и настройки** — примеры правил, шаблоны ответов и карточки параметров демонстрационной организации.

Вёрстка адаптивная; Bootstrap Icons и Chart.js используются с CDN. Для их загрузки и веб-шрифтов нужен интернет. Сами Spring Boot, Thymeleaf и база H2 работают локально.

## Используемые технологии

- Java 21, Spring Boot 3, Spring MVC.
- Maven.
- Thymeleaf и Bootstrap 5; отдельного SPA-фронтенда нет.
- Spring Data JPA и H2 в памяти.
- Bootstrap Icons и Chart.js для иконок и диаграмм.

## Ограничения демонстрационной версии

- Демо-пароль преднамеренно задан в приложении и не должен использоваться в рабочей системе.
- Каналы связи представлены демонстрационными метками и иконками; отправки писем и сообщений нет.
- Загрузка файлов и вставка эмодзи в карточке обращения намеренно отключены.
- Примеры правил и шаблонов на странице автоматизации не исполняются.
- Настройки, теги и данные команды приведены для визуальной демонстрации и не являются полноценной системой управления.
- H2-консоль доступна локально по `/h2-console`; приложение не предназначено для публикации в открытый интернет.

## Лицензии и ресурсы

Spring Boot, Thymeleaf, Bootstrap, Bootstrap Icons, Chart.js и веб-шрифты подключаются и используются в рамках собственных лицензий. CDN-ресурсы загружаются браузером; сборка не устанавливает npm-зависимости и не содержит React.
